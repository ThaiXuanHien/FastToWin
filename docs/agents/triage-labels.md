# Triage labels

| Vai trò chuẩn | Nhãn trên GitHub | Ý nghĩa |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Cần maintainer đánh giá issue |
| `needs-info` | `needs-info` | Đang chờ người báo lỗi bổ sung thông tin |
| `ready-for-agent` | `ready-for-agent` | Đã đủ đặc tả để agent triển khai |
| `ready-for-human` | `ready-for-human` | Cần con người trực tiếp xử lý |
| `wontfix` | `wontfix` | Không triển khai |

Khi skill nhắc tới một vai trò triage, sử dụng nhãn GitHub tương ứng trong bảng.
